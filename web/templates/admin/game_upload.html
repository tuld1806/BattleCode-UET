Quy Định Cấu Trúc Plugin .ZIP

File .zip plugin hợp lệ bắt buộc phải có cấu trúc thư mục tối thiểu:

game_plugin.zip
├── game.yaml         # Khai báo slug, display_name, board_size
├── engine.py         # Kế thừa GameEngine (engine/base.py)
└── rules.md          # Hướng dẫn chi tiết luật chơi
  • Nghiêm cấm import các thư viện mạng hoặc thao tác filesystem trái phép (sẽ bị AST validator từ chối).
  • Hàm create_initial_board() và apply_move() phải tuân thủ trừu tượng của nền tảng.
